# 维护交接

## 当前基线

项目源码仓库为 `Skyoslabs/FreeSSL`，维护分支为 `main`，当前产品版本为 **v1.0.0**，许可证为 MIT。本轮只整理开发交接和迁移工作目录，保留现有程序、版本及安装包。

源代码、依赖锁、上游源码与许可、图标、构建脚本、测试、GitHub Actions 和项目文档共同构成维护所需文件。根目录 `freessl.html` / `freessl.php` 是生成文件，实际修改入口在 `src/`。构建和发布步骤见 [开发说明](development.md)，协议与存储方案见 [技术说明](technical.md)。

## 已确认的产品约定

- 对外名称为 Free SSL，程序与安装包使用小写 `freessl` 文件名。
- 只交付一个安装包，包含 `freessl.html`、`freessl.php`、`readme.md`。HTML 为入口，自动探测同目录 PHP；不拆成本地版、在线版等多个产品。
- PHP 可用时优先服务器签发，没有现成 HTTPS 的网站也能申请首张证书。无 PHP 时保留浏览器文件 / DNS 引导。
- 只使用 Let’s Encrypt 正式签发环境，支持普通域名、泛域名、多域名、RSA 与 ECDSA。模拟环境仅用于开发检查。
- 首次打开自行设置密码。登录后生成证书，PEM / KEY 同页明文显示，支持独立复制和下载，自动保存记录。
- 导航为申请证书、我的证书、退出登录。申请区区分本站与其他网站，证书按域名管理，续期从“我的证书”进入。
- PHP 本站文件验证自动放置；其他网站文件验证和所有 DNS 验证按页面引导操作。即使支持文件验证，也允许使用者主动选择 DNS。
- 文件验证只提供一个验证 ZIP 下载入口，手动创建目录和文件的方法默认收起。申请状态需清楚可见，说明使用容易理解的语言。
- 支持根目录和子目录部署。程序及记录留在安装目录，HTTP 验证文件仍在网站根目录的固定验证路径。
- PHP 忘记密码时删除 `freessl-password.php`，重新设置密码；保留账户、证书及待验证订单。浏览器加密记录需要原密码，移动 HTML 页面会影响原记录访问。
- PHP 会话有效期保持当前 30 天规则。续期由使用者打开页面点击触发；程序签发证书后，由使用者将新 PEM / KEY 安装到主机。

## 开发与发布

使用 Node.js 24.18+、npm 11.16+，在源码根目录执行：

```sh
npm ci
npm run pack:install
npm run check
```

`docs/usage.md` 是安装包使用说明的唯一来源。`dist/freessl.zip` 为可重复构建的交付包；开发资料、模拟服务和运行数据不进入安装包。Logo 与 favicon 的源文件在 `assets/`，程序所需图标已嵌入 HTML。

仅文档整理或工作目录迁移沿用当前版本。需要发布程序修改时，先更新版本和变更记录，构建并检查，为确认的提交创建版本标签与 Release，只附上安装 ZIP 并记录 SHA-256。

迁移和纯文档整理采用简单核对：文件迁入完整、现有构建可用、GitHub 提交已同步即可；按修改范围验证，避免重复或扩大检查。

## 验证证据

2026-09-28，使用者明确确认 PHP 公网域名验证和证书签发已在实际网站通过。这是使用者提供的实测结论，不记录具体申请域名、主机地址或服务器编号。

本机自动检查使用真实 Web Crypto、PHP 8.4 / OpenSSL 与模拟 CA，覆盖浏览器与 PHP 的申请、续期、密码重置、证书匹配及安装包一致性。当前检查共 26 项。GitHub Actions 执行同一套构建和检查，不向公共 CA 注册测试账户。

此前 Chrome 界面复查覆盖 PHP 与浏览器模式、DNS 主动选择、申请状态、PEM / KEY 展示、手动文件方法、记录恢复、按域名续期和密码重置说明。后续根据实际修改范围复查，不把签发成功写成主机安装完成。
