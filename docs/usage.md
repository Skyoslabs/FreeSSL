# Free SSL 使用说明

适用于 v1.0.0。

Free SSL 帮你申请免费的 Let’s Encrypt SSL 证书。打开网页，填写域名，按提示完成验证，就能拿到证书 PEM 和私钥 KEY，再复制到主机面板安装。整个过程不用命令行。

安装包只有一份，里面有三个文件：

- `freessl.html`：每次都从这个页面进入。
- `freessl.php`：网站支持 PHP 时，负责申请证书和保存记录。
- `readme.md`：这份使用说明。

## 1. 安装和打开

### 放在网站上

1. 解压 `freessl.zip`，把三个文件上传到网站的同一个目录。
2. 用浏览器打开该目录里的 `freessl.html`。
3. 首次进入，自己设置一个至少 8 个字符的密码。设置后自动登录，以后用这个密码进入。

可以放在网站根目录，也可以放在子目录，例如：

| 上传位置 | 打开地址 |
| --- | --- |
| 网站根目录 | `http://example.com/freessl.html` |
| 根目录下的 `tools/freessl/` | `http://example.com/tools/freessl/freessl.html` |

网站已经有 HTTPS 时，也可以使用对应的 HTTPS 地址。不要覆盖原网站的首页，两个程序文件也不要改名或分开放。

页面会自动检测 PHP。能用时优先使用 PHP；页面上方的“重新检测 PHP”可再次检查。PHP 模式不需要网站先有证书，原来只有 HTTP 也能使用。

网站需要支持 PHP 8.1 或更新版本、OpenSSL，并允许 PHP 连接外网和保存文件。多数主机面板可在网站设置里选择 PHP 版本；如果检测失败，请先检查这些设置。

### 在电脑上打开，或网站不支持 PHP

直接用 Chrome 打开解压后的 `freessl.html`，同样先设置密码。按网页提示手动上传验证文件，或者添加 DNS 记录。

如果 HTML 放在不支持 PHP 的 HTTPS 网站上，也可以直接按页面提示申请。如果是没有 PHP 的 HTTP 网站，页面会提示改在电脑上打开安装包里的 HTML，再继续操作。

## 2. 申请证书

点击右上角“申请证书”，先选择“为本站申请”或“为其他网站申请”，再填写域名，例如 `example.com`。不要填写 `https://`、端口或网址路径。

一张证书要包含多个域名时，展开“高级选项”，在附加域名里填写其他域名，每行一个。例如主域名和 `www` 域名需要一起使用，就把两个都填上。默认密钥类型通常可以直接使用。

验证方式由你选择：

- **文件验证**：PHP 为本站申请时，自动创建验证文件并完成签发，你不用上传。为其他网站申请，或没有 PHP 时，按页面提示上传文件。
- **DNS 验证**：在域名服务商的解析设置里添加 TXT 记录。即使本站支持自动文件验证，也可以选择 DNS。`*.example.com` 这样的泛域名必须用 DNS 验证；如果还要覆盖 `example.com`，也要把它加入证书域名。

阅读并勾选 Let’s Encrypt 服务条款，点击申请。申请过程中，页面底部会显示当前进度；等它完成即可。

### 手动上传验证文件

1. 点击“下载验证文件包 ZIP”。
2. 在主机面板打开目标网站的“文件管理”，进入**网站根目录**。
3. 上传 ZIP，解压到当前目录。应出现 `.well-known/acme-challenge/` 文件夹。
4. 逐个打开页面给出的验证网址，确认内容一致，再勾选确认框，点击“提交验证并取得证书”。

如果不方便上传 ZIP，点击页面中收起的“无法上传或者不想上传，手动创建文件夹及验证文件”。在网站根目录依次新建 `.well-known`、`acme-challenge` 文件夹，然后按页面给出的文件名新建文件、粘贴内容。文件名不加 `.txt` 等后缀，内容保存为纯文本。

多个域名指向同一个网站根目录，只需上传一次；指向不同目录时，要分别放到各自的网站根目录。

### 程序放在子目录时，验证文件放哪里？

程序可以放在 `tools/freessl/` 等子目录，**验证文件仍然放在网站根目录**。例如程序地址是：

`http://example.com/tools/freessl/freessl.html`

验证网址仍然是：

`http://example.com/.well-known/acme-challenge/页面给出的文件名`

验证网址中不能带 `tools/freessl/`。PHP 为本站自动验证时，会按服务器提供的网站根目录写入验证文件；手动上传时，也要把 ZIP 解压到网站根目录，不能解压到程序所在的子目录。

PHP 需要能写入网站根目录下的验证目录。如果主机限制了写入权限，或服务器提供的根目录与域名实际访问目录不一致，可以在主机面板调整目录权限和网站根目录设置，也可以改用 DNS，或在电脑上打开 HTML 手动上传文件。DNS 验证不受程序所在目录影响。

### DNS 验证

1. 登录域名的 DNS 服务商面板，进入解析设置。
2. 按页面给出的记录名、记录值，添加 TXT 记录。网站原有的 A、CNAME 等记录不用改。
3. 等待解析生效，勾选确认框，再提交验证。

面板会自动补上域名时，只填前半段。例如完整记录名为 `_acme-challenge.blog.example.com`，在 `example.com` 的面板中，“主机记录”填写 `_acme-challenge.blog`。

页面给出多个相同记录名、不同记录值时，要逐条添加并同时保留，不能后一条覆盖前一条。解析生效时间以域名服务商为准。

## 3. 安装和下载证书

申请成功后，页面进入“我的证书”，直接显示两段内容：

- **证书 PEM**：复制到主机面板的“证书 / PEM / Certificate”框。
- **私钥 KEY**：复制到同一处的“私钥 / KEY / Private Key”框。

把两段完整复制进去，保留开头、结尾和换行，保存后打开网站的 HTTPS 地址，确认能正常访问。主机面板如果要求证书链，使用这里的完整 PEM 内容即可。

也可以点击“下载完整证书包”，里面包含 `fullchain.pem`、`privkey.pem` 和安装提示。两个文件支持单独下载。

Free SSL 负责申请证书。证书还需要安装到主机面板，网站才会开始使用；申请成功不会自动修改网站的 SSL 设置。

证书包里有私钥，请保存在自己的电脑，不要放到网站公开目录。申请时会将域名和公钥发送给 Let’s Encrypt，私钥不会发送给它。

## 4. 查看和续期

以后打开同一个页面，登录后点击“我的证书”。每个域名单独显示，找到需要处理的域名即可：

- “查看 PEM / KEY 与下载”：打开已经保存的证书和私钥。
- “一键续期”：开始为这个域名续期。
- “继续验证”：接着完成尚未结束的申请。

PHP 本站文件验证会自动完成续期；其他网站、手动文件验证或 DNS 验证，按页面上传这次的文件或添加这次的 TXT 记录。**旧文件和旧记录不一定能用于下次验证**，以页面给出的内容为准。

还没到建议续期日期时，点击续期会打开现有证书。续期完成后，要把新的 PEM 和 KEY 一起替换到主机面板，这样网站才会用上新证书。

## 5. 记录保存在哪里？

**PHP 模式**自动把申请记录、证书和私钥保存到程序所在目录。以后打开同一个网站页面，登录后可继续管理；未完成的验证也能在“我的证书”中继续。备份或迁移程序时，要一起备份该目录后来生成的运行文件，不要只复制最初的三个文件。

**电脑 HTML 或无 PHP 模式**在申请成功后，自动用登录密码加密保存到当前浏览器。下次使用同一个浏览器、同一个文件位置或网址进入。换电脑、换浏览器、清理浏览器数据，可能看不到原来的记录；请下载证书包留存。手动申请还没完成时，不要关闭或刷新页面。

点击“退出登录”后，再次进入需要输入密码，已保存的证书不会删除。

## 6. 忘记密码，自己怎么重置？

### 网站 PHP 模式：删除一个文件就行

1. 在主机面板打开“文件管理”，进入 Free SSL 所在目录，也就是放着 `freessl.html`、`freessl.php` 的目录。
2. **只删除 `freessl-password.php`**。这是设置密码后自动生成的文件，不在最初的安装包里。
3. 重新打开 `freessl.html`，自行设置新密码，然后进入。

已有证书、私钥、申请记录都保留，原来的登录会失效。不用找别人，也不用重新下载安装包。重新上传覆盖 HTML/PHP 不会重置密码。

不要删除 `ssl-helper.config.php` 或其他证书、私钥文件。程序放在子目录时，就在该子目录删除密码文件，不是在网站根目录找。

### 在电脑上打开 HTML：复制到新文件夹

把 `freessl.html` 复制到一个新的文件夹，再打开，就可以设置新密码、重新开始使用。没有 PHP 的静态网站，也可以把 HTML 放到新的子目录后打开。

新位置的“我的证书”从空白开始。原来的记录是用旧密码加密的，新密码不能解锁；旧文件和浏览器数据不用删。已下载的证书包和网站正在使用的证书不受影响，可以继续使用。

## 7. 遇到问题

- **验证网址显示 404**：检查文件是不是放在目标网站根目录，名称是否完整，是否误加了 `.txt` 后缀。子目录安装时尤其要区分程序目录与网站根目录。
- **验证网址出现首页、登录页或验证码**：网站的跳转、伪静态或防护规则拦住了验证路径。让 `.well-known/acme-challenge/` 能直接打开对应文件，或改用 DNS。
- **文件能打开，但仍然验证失败**：检查所有申请域名是否指向对应网站，公网 HTTP 的 80 端口是否可访问。按页面提示重新生成文件后，再试一次。
- **DNS 验证失败**：检查记录类型是 TXT、记录名没有重复补上域名、记录值完整，并确认所有记录已经生效。
- **PHP 检测失败**：确认两个程序文件在同一个目录，主机已启用合适的 PHP 版本、OpenSSL、外网连接和目录写入权限。暂时不能使用 PHP 时，在电脑上打开 HTML 继续申请。
- **申请次数达到限制**：按 Let’s Encrypt 返回的提示等待，不要连续重复申请。
- **忘记密码**：按上面的步骤操作，PHP 模式删除 `freessl-password.php`；电脑 HTML 模式复制到新文件夹打开。
